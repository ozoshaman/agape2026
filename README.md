# Ágape 2026 🏁

Sitio web oficial de la Reunión Juvenil Ágape 2026 — Iglesia de Cristo.
Temática: Fórmula 1.

**Fecha del evento:** 11 y 12 de diciembre de 2026

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Supabase (PostgreSQL)
- Despliegue en Vercel

## Cómo correr el proyecto localmente

```bash
   npm install
   npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)
